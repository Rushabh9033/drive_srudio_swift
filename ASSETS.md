# Drive Studio — Media assets

## Fictional garage brands (no trademarks)

Garage home brands remain **in-house fictional marques**. UI labels never show BMW / Audi / Tesla / Mercedes / Ferrari (etc.) names or badge artwork in Garage catalog rows.

| Brand | Tagline | Models |
|-------|---------|--------|
| Aurelio | Sculpted grand touring | GT Corsa, Lumen S, Vento |
| Velora | Electric performance | V8 Pulse, EX Coupe, Arc Sedan |
| Northstar | Expedition utility | Trail 90, Peak XL |
| Kinetic | Urban compact | Mono One, Flux |

Editor **Logo / Stock car** flows use common make **names as text** (Toyota, BMW, …) for UX. Marks are abstract monogram PNGs — never OEM trademark artwork.

Stock photographs may depict real-world vehicle designs from public photo libraries. Do not ship trademarked logo PNG packs.

## Abstract brand logos (lettermarks)

| Path | Contents |
|------|----------|
| `assets/logos/<slug>.png` | Abstract monogram / badge mark (256×256 PNG) per make |

Generated by `python tool/generate_brand_logos.py`. Lettermarks only (e.g. “BM”, “TY”, “MB”) in a circle — **not** BMW roundels, Mercedes stars, etc.

Examples: `bmw.png`, `toyota.png`, `mercedes-benz.png`, `alfa-romeo.png`.

## Vehicle imagery (photographic, car-only crops)

| Path | Contents |
|------|----------|
| `assets/vehicles/{coupe,sedan,suv,wagon,roadster,hatch}.png` | Body-style heroes (1280×720, tight car crop) |
| `assets/vehicles/models/<modelId>.png` | Fictional garage per-model heroes |
| `assets/vehicles/stock/<id>.png` | Editor stock cars with angle tags |

`VehicleArt` loads the model photo when `modelId` is set, otherwise the body-style photo, and falls back to a painted silhouette **only** if decode fails. Custom user uploads still win when `vehicle.customImage` is set.

Stock picker filters by body class + angle (`front34` / `side` / `rear34`). Brand→model picker shows a cropped car thumb when a mapping or body-class fallback exists.

### Regenerate

```powershell
python tool/generate_brand_logos.py
python tool/fetch_vehicle_photos.py
```

Manifest written to `tool/vehicle_photo_manifest.json`.

### Swap later

1. Drop photographic JPEG/PNG files using the **same filenames**.
2. Keep aspect ~16:9; 1280×720 works well. Prefer car filling the frame.
3. `flutter pub get` then **full restart** (hot reload will not pick up replaced assets):

```bash
flutter run -d chrome --web-port=5173
# or: flutter run
```

## Sound cues

| Path | Contents |
|------|----------|
| `assets/sounds/<cue-id>.wav` | All **17** catalog cues (mono 44.1 kHz PCM, ~1.15s) |

These are **automation cues**, not music:

| Slot | Meaning |
|------|---------|
| **Connect** | Plays when iPhone connects to the car (CarPlay / Bluetooth) via Shortcuts |
| **Disconnect** | Plays when the phone disconnects from the car |
| **Reminder** | Optional cue for a reminder automation |

`TonePlayer` plays via `audioplayers` `AssetSource` first; sine-synth WAV remains the fallback if an asset is missing (fallback pitch is unique per cue id).

**Playback output** (Sounds tab / Settings): Phone · Car · Auto. On iOS, `AVAudioSession` is set to loudspeaker (`playAndRecord` + `defaultToSpeaker`) for Phone, or `playback` (follows Bluetooth / car stereo) for Car. Auto uses car route when Car link is on, otherwise phone speakers. The master sound pack does not ship separate phone/car WAV folders — routing is session-based.

Cue IDs match `Catalog.sounds`. Regenerate WAVs only: `python tool/generate_media_assets.py` (sounds section), or replace files and keep filenames.
